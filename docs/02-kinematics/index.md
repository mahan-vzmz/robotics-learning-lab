# فصل ۲: سینماتیک ربات سیار

اسلایدهای استاد را بخوان، سپس این فصل را به ترتیب زیر پیش ببر:

1. [توضیح‌های تکمیلی رفرنس](reference-additions.md): نکته‌هایی که اسلاید کوتاه گفته یا وارد جزئیاتشان نشده است.
2. [مرور فصل](review.md): پیوند مفاهیم و خطاهای رایج.
3. [برگهٔ فرمول](formula-sheet.md): قراردادها، واحدها و رابطه‌ها.
4. [۱۴ تمرین در هفت سطح](exercises.md): ابتدا بدون پاسخ‌نامه حل کن.
5. [پاسخ‌نامه](solutions.md): روش حل و فرض‌ها را با کار خودت مقایسه کن.

این نسخه نخستین بستهٔ تمرینِ بررسی‌شده است، نه بانک کامل فصل. فایل نمونهٔ ۷۵ مسئله‌ای جداگانه در صف بررسی می‌ماند؛ تعداد سؤال به‌تنهایی معیار کامل‌بودن پوشش نیست.
