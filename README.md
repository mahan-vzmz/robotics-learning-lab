# آزمایشگاه یادگیری رباتیک

درس‌نامه‌ای فارسی برای یادگیری رباتیک، از فهم مسئله تا مدل‌سازی و آزمایش. این پروژه از نو در حال تألیف است؛ فعلاً فقط نخستین درس آمادهٔ مطالعه است.

## شروع مطالعه

[درس ۱: ربات، خودگردانی و چرخهٔ ادراک تا عمل](docs/01-introduction.md) را بخوانید و سه تمرین پایان آن را حل کنید. برای خواندن فایل‌ها فقط یک نمایشگر Markdown لازم است.

## روش تألیف

ترتیب درس‌ها از اسلایدهای درس «اصول رباتیک» دکتر آرمین سلیمی بدر الهام می‌گیرد. توضیح‌ها، مثال‌ها و تمرین‌ها مستقل نوشته می‌شوند. یادداشت‌های دست‌نویس دانشجو سرنخ آموزشی‌اند و پیش از ورود به درس‌نامه با منابع دیگر بررسی می‌شوند.

دو مرجع فعلی عبارت‌اند از *Elements of Robotics* اثر Ben-Ari و Mondada (۲۰۱۸)، و **ویرایش ۲۰۰۴** *Introduction to Autonomous Mobile Robots* اثر Siegwart و Nourbakhsh. شمارهٔ صفحهٔ این ویرایش را نباید به ویرایش دوم ۲۰۱۱ نسبت داد.
