# آزمایشگاه یادگیری رباتیک

درس‌نامه و بانک تمرین فارسی برای یادگیری رباتیک، از اسلاید درس تا مباحث تکمیلی کتاب و حل مسئله. فصل‌ها به‌تدریج نوشته و بازبینی می‌شوند.

## شروع مطالعه

ابتدا اسلاید استاد را بخوان، سپس توضیح تکمیلی، مرور، برگهٔ فرمول و تمرین‌های همان فصل را به ترتیب پیش ببر:

- [فصل ۱: ربات، خودگردانی و چرخهٔ ادراک تا عمل](docs/01-introduction.md) — درس آغازین و سه پرسش.
- [فصل ۲: سینماتیک ربات سیار](docs/02-kinematics/index.md) — توضیح‌های تکمیلی، مرور، فرمول‌ها و ۱۴ تمرین با پاسخ در هفت سطح.

## روش تألیف

ترتیب درس‌ها از اسلایدهای درس «اصول رباتیک» دکتر آرمین سلیمی بدر الهام می‌گیرد. **اولویت اول تمرین‌های باپاسخ و بررسی‌شده، و اولویت دوم توضیح شکاف‌های اسلاید با رفرنس‌هاست.** تمرین‌ها و توضیح‌ها مستقل نوشته می‌شوند و منشأ مطالب استاد، کتاب و تألیف پروژه از هم جدا می‌ماند. یادداشت‌های دست‌نویس دانشجو پیش از ورود به درس‌نامه با منابع دیگر بررسی می‌شوند.

دو مرجع فعلی عبارت‌اند از *Elements of Robotics* اثر Ben-Ari و Mondada (۲۰۱۸)، و **ویرایش ۲۰۰۴** *Introduction to Autonomous Mobile Robots* اثر Siegwart و Nourbakhsh. شمارهٔ صفحهٔ این ویرایش را نباید به ویرایش دوم ۲۰۱۱ نسبت داد.
